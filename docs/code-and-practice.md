adds code reading, debugging and skills evidence without pretending a certification.

Azure/cloud gap: the repositories do not demonstrate resource provisioning, managed
identity, backup objectives or cloud incident operations. Explain the proposed boundary
and acceptance evidence instead of claiming Azure experience from local Ollama/.NET.
Power Platform gap: Noordwerk has handoff/contracts, not a managed solution tested in a
tenant. Be able to explain environment variables, connection ownership and one system
of record; actual import/persona/recovery evidence remains a future authorised exercise.
