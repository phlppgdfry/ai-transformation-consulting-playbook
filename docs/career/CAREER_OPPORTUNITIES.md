## Search criteria and application discipline

Use employer pages/VDAB with `functioneel analist`, `business applications analyst`,
`junior business consultant`, `implementatieconsultant`, `digital transformation analyst`,
`AI implementation consultant` and `product analyst`. Locations: Brugge/Zeebrugge/Oostende
first, then Ghent/Kortrijk within the owner's actual commute. Filter for junior/mentoring;
read hard gates before counting an opportunity. An internship is relevant only if the
owner meets its student/academic conditions.

Track role URL, check date, hard gates, owner-confirmed facts, one relevant artifact,
specific preparation, application/message date and follow-up. Record private applications
outside public GitHub. Aim for a small set of well-matched applications, not a mass send.
Never treat a current listing as permanent: refresh its official page on submission day.
